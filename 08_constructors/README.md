# Task 8: Object Constructors

### What is a Constructor?
A special function that runs automatically the exact moment an object is created.

### Terminal Output
```text
Default constructor called!
Bot 1 Name: Unknown Robot

Parameterized constructor called!
Bot 2 Name: RoboOne
```
### Summary
* **Default Constructor:** Gives a fallback name ("Unknown Robot") if we don't provide one.
* **Parameterized Constructor:** Allows us to set a custom name immediately upon creation.
